## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Proxmox API | Terraform authenticates to Proxmox via API token from base-infra |
| SSH to LXC | SSH access from operator workstation to LXC containers via cert-based auth |
| Transfer VLAN | Cross-node cluster traffic on 192.168.11.x (internal, not internet-facing) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | S (Spoofing) | Transfer VLAN traffic | accept | VLAN isolation provides network-level separation; no internet exposure. Cluster services (etcd, PG replication) will add TLS in later phases if needed. |
| T-06-02 | T (Tampering) | Ansible inventory file | mitigate | Generated inventory file has 0644 permissions via local_file resource; file header warns "do not edit manually". Git tracks the file for change detection. |
