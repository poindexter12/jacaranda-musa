## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SSH from operator | Justfile recipes SSH to LXC containers as root |
| Multi-host iteration | Recipes loop over hosts array — a DNS poisoning attack on .lan could redirect SSH |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-06 | S (Spoofing) | SSH host verification | mitigate | LXC module signs host certificates via SSH CA. SSH verifies host identity on each connection. Operator workstation trusts the CA. |
| T-06-07 | T (Tampering) | Rollback snapshots | accept | Rollback .bak files stored on each LXC at /opt/musa/. Root-only access. Low risk for test environment. |
| T-06-08 | I (Information Disclosure) | Justfile secrets | mitigate | Secrets passed as ansible extra-vars via secret-read script. Never logged to stdout. ANSIBLE_LOG_PATH captures playbook output but secrets marked no_log in Ansible tasks. |
</threat_model>
