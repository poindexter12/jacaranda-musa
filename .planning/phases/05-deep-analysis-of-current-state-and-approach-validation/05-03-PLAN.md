  <name>Task 2: Add rollback recipe to test.just</name>

  <action>
Add a `rollback` recipe to test.just in the Workflows section. The rollback strategy:

1. Before each deploy, the Ansible deploy recipe already re-renders templates. But there's no pre-deploy backup.
2. The rollback recipe should:
   a. SSH to `musa-test.lan` and check that `.bak` files exist (created by the rollback-prep step below)
   b. Restore `docker-compose.yaml.bak` → `docker-compose.yaml` and `.env.bak` → `.env`
   c. Run `docker compose up -d --force-recreate`
   d. Wait 30s then check health

Also add a `rollback-prep` recipe that creates the `.bak` snapshots. This should be called at the START of the `deploy` recipe.

**Implementation:**

Add to test.just before the Workflows section:

```just
# ============================================================================
# Rollback
# ============================================================================

# Save current config as rollback point (called before deploy)
[private]
rollback-prep:
    #!/usr/bin/env bash
    set -euo pipefail
    host="musa-test"
    printf '%b-> Saving rollback snapshot%b\n' '{{ CYAN }}' '{{ NC }}'
    ssh -o BatchMode=yes root@$host.lan "cd /opt/musa && \
        cp -f docker-compose.yaml docker-compose.yaml.bak 2>/dev/null && \
        cp -f .env .env.bak 2>/dev/null" || true

# Rollback to previous deployment
[confirm("Roll back Musa test to previous deployment?")]
rollback:
    #!/usr/bin/env bash
    set -euo pipefail
    host="musa-test"

    printf '%b=== Rolling back Musa (test) ===%b\n' '{{ BOLD }}' '{{ NC }}'

    # Check backup files exist
    if ! ssh -o BatchMode=yes root@$host.lan "test -f /opt/musa/docker-compose.yaml.bak"; then
        printf '%b  FAIL: No rollback snapshot found. Run a deploy first.%b\n' '{{ RED }}' '{{ NC }}'
        exit 1
    fi

    # Restore backup files
    ssh -o BatchMode=yes root@$host.lan "cd /opt/musa && \
        cp -f docker-compose.yaml.bak docker-compose.yaml && \
        cp -f .env.bak .env"
    printf '%b  Restored config from snapshot%b\n' '{{ GREEN }}' '{{ NC }}'

    # Recreate containers
    ssh -o BatchMode=yes root@$host.lan "cd /opt/musa && docker compose up -d --force-recreate"
    printf '%b  Waiting 30s for services to start...%b\n' '{{ CYAN }}' '{{ NC }}'
    sleep 30

    # Quick health check
    if ssh -o BatchMode=yes root@$host.lan "curl -sf http://localhost:3000/healthz" >/dev/null 2>&1; then
        printf '%b  Rollback OK — Twenty CRM healthy%b\n' '{{ GREEN }}' '{{ NC }}'
    else
        printf '%b  WARNING: Twenty CRM health check failed after rollback%b\n' '{{ RED }}' '{{ NC }}'
        exit 1
    fi
```

Then modify the `deploy` recipe to call `rollback-prep` before the ansible-playbook run. Add this line as the first command in the deploy recipe bash block:

```bash
just test::rollback-prep
```

This ensures every deploy creates a rollback snapshot before overwriting configs.
