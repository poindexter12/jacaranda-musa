<task type="auto">
  <name>Task 2: Tighten health checks and add Ansible curl timeouts</name>
  <files>ansible/roles/musa/templates/docker-compose.yaml.j2, ansible/roles/musa/tasks/main.yaml</files>
  <action>
**Step 1: Tighten server health check in docker-compose.yaml.j2.**

Change the `server` service healthcheck from:
```yaml
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:3000/healthz"]
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 60s
```
To:
```yaml
    healthcheck:
      test: ["CMD", "curl", "-sf", "--max-time", "5", "http://localhost:3000/healthz"]
      interval: 10s
      timeout: 5s
      retries: 5
      start_period: 60s
```

Changes: interval 30s→10s, timeout 10s→5s, retries 3→5, add `--max-time 5` and `-s` to curl. Keep start_period at 60s (Twenty needs time for DB migrations on first start).

**Step 2: Tighten webhook-receiver health check similarly.**

Change webhook-receiver healthcheck from:
```yaml
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:5000/health"]
      interval: 30s
      timeout: 5s
      retries: 3
      start_period: 10s
```
To:
```yaml
    healthcheck:
      test: ["CMD", "curl", "-sf", "--max-time", "5", "http://localhost:5000/health"]
      interval: 10s
      timeout: 5s
      retries: 5
      start_period: 10s
```

**Step 3: Add explicit curl timeouts to Ansible health check tasks in `ansible/roles/musa/tasks/main.yaml`.**

For the "Wait for SWAG to respond" task, add `--max-time 5` to the curl command:
```yaml
    cmd: docker exec twenty-swag curl -sf -o /dev/null -w '%{http_code}' --max-time 5 http://localhost:80
```

Also reduce the Ansible-level retries/delay to be tighter:
- SWAG: retries 30→12, delay 5→5 (60s total instead of 150s)
- Twenty healthz: retries 30→12, delay 10→10 (120s total instead of 300s — still plenty for migrations)

For the "Wait for Twenty CRM health check" task, add a `timeout` parameter to the `ansible.builtin.uri` module:
```yaml
  ansible.builtin.uri:
    url: "http://localhost:3000/healthz"
    timeout: 10
```

  </verify>
